# 4차시 — 현대어·근대어별 OCR 방법론과 파이썬 실무

**부산대학교 · 2026년 8월 12일(수) 15:00 · 120분**

어제는 글자만 있는 쪽이었다. 실제 사료가 그렇게 생긴 경우는 드물다.
이 시간에는 사진과 목록이 든 쪽을 직접 돌려 보고, 세로쓰기·국한문 근대 지면까지
사다리를 올라가며 어디서 무너지는지 본다.

**어제 만든 사본이 아니라 아래 링크에서 새 노트북을 연다.** 런타임이 새로 뜨므로
①칸부터 다시 실행한다.

직접 고치는 칸은 실습 노트북 **③ 하나뿐이다.** 어제와 같다.

⑤칸부터 열쇠가 필요하다. 어제는 화면으로만 보셨던 자리다.

## 준비할 것

어제와 같다. 절차는 **[API 키 발급 안내](../../docs/api-key-setup.md)** 에 있다.

- **Vision API 키 파일(`.json`)** — Google Drive의 `keys` 폴더에 있어야 한다.
  노트북 ②칸이 그 폴더에서 찾아 쓴다.
- **Gemini API 키 문자열** — 코랩 왼쪽 열쇠 아이콘에 `GEMINI_API_KEY` 로 등록한다.
  등록하지 않았으면 실행할 때 붙여넣는 칸이 뜬다.

**어제 못 받으신 분은 실습 앞머리나 휴식 때 말씀해 주십시오.**

## 실습 사료

| | 자료 | 무엇이 들어 있나 |
|---|---|---|
| **A** | 부산광복 60년 발췌본 3쪽 (원본 203쪽) | 본문 + 사진 + 사진 설명 |
| **B** | 내사랑 부산바다 243쪽 | 지명 대조 목록 15줄 + 사진이 목록을 가름 |

**A는 어제 긁어보신 그 파일이다.** 노트북 ①칸이 3차시 폴더에서 그대로 받아온다.

B의 목록은 「옛 지명(한자) ‑ 일제강점기 지명(한자)」 꼴로 짝을 이룬다.
**짝이 맞으니 몇 개가 살아남았는지 셀 수 있다.** ⑦칸이 그 일을 한다.

시연에 쓰는 근대 지면은 [`data/`](data/) 에 있다.

## 자주 막히는 곳

**드라이브 keys 폴더에 파일이 없다.** 어제와 같다. 발급 안내 5-2를 확인한다.

**빈 응답이 온다.** 목록이 든 쪽에서 실제로 일어난다. ⑥칸이 경고를 찍어 준다.
한 번 더 실행하면 대개 나온다. **본인 잘못이 아니다.**

**같은 말을 반복하며 길어진다.** 이것도 ⑥칸이 잡아낸다. 그 결과는 쓰지 않는다.

**칸을 건너뛰었다.** 앞 칸이 만든 것을 뒤 칸이 받아 쓴다.

## 비용

어제와 같다. **Vision**은 월 1,000장까지 무료, **Gemini**는 한 장에 몇 원 수준이다.
이날 실습은 두 장을 돌리므로 십원 단위다.

워크숍이 끝나고 더 쓸 일이 없으면 프로젝트를 종료하거나 서비스 계정 키를 삭제한다.
자세한 것은 발급 안내 6절에 있다.

## 이 시간의 요지

틀린 것은 눈에 띈다. 없어진 것은 스스로 드러나지 않아 세어봐야 안다.
에러도 나지 않고 결과물은 멀쩡해 보인다.

파이프라인은 범용이다. 자료가 바뀌어도 코드는 그대로고, 바뀌어야 하는 것은
지시문이다. 그래도 넘지 못하는 선이 있다.
