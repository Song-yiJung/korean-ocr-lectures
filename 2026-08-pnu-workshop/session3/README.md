# 3차시 — 비정형 사료의 디지털화

**부산대학교 · 2026년 8월 11일(화) 15:00 · 120분**

스캔본 PDF에는 글자가 들어 있지 않다. 이 시간에는 그것을 눈과 코드로 확인하고,
Google Cloud Vision과 Gemini를 이어 붙여 한 쪽에서 텍스트를 뽑아내는 전 과정을 본다.
코랩을 처음 쓰는 사람을 기준으로 만들었다.

## 실습 노트북

**위에서부터 차례로 연다.** 각 노트북을 열면 맨 위에 `파일 → 드라이브에 사본 저장`
안내가 있다. 원본은 읽기 전용이므로 반드시 사본에서 작업한다.

| | 하는 일 | 시간 |
|---|---|---|
| **[텍스트 레이어 확인](https://colab.research.google.com/github/Song-yiJung/korean-ocr-lectures/blob/main/2026-08-pnu-workshop/session3/0_텍스트레이어_확인.ipynb)** | PDF 안에 글자가 몇 자 들어 있는지 센다 | 약 10분 |
| **[OCR 실습](https://colab.research.google.com/github/Song-yiJung/korean-ocr-lectures/blob/main/2026-08-pnu-workshop/session3/ocr_실습.ipynb)** | PDF → 사진 → 글자 → 문맥 교정 | 약 40분 |

직접 고치는 칸은 **③ 하나뿐이다.** 나머지는 ▶ 만 누르면 된다.

이날 참가자가 직접 돌리는 것은 **⑤칸까지**다. 열쇠가 필요한 ⑥칸부터는 화면으로 보고,
4차시에 각자 돌린다.

## 강의 전날까지 준비할 것

당일에 하면 시간이 모자란다. 절차는 **[API 키 발급 안내](../../docs/api-key-setup.md)**
한 곳에 그림과 함께 정리되어 있다.

두 키는 **생김새가 다르다.** Vision은 *파일*, Gemini는 *문자열 한 줄*이다.
이 둘을 바꿔 넣는 것이 가장 흔한 실수다.

- **Vision API 키 파일(`.json`)** — **Google Drive의 `keys` 폴더에 올려 두어야 한다.**
  코랩은 본인 PC의 바탕화면을 볼 수 없다. 노트북 ②칸이 그 폴더에서 찾아 쓴다.
- **Gemini API 키 문자열** — 코랩 왼쪽 열쇠 아이콘(보안 비밀)에 `GEMINI_API_KEY`
  라는 이름으로 등록한다. 이름이 글자 하나라도 다르면 노트북이 읽지 못한다.
  등록할 때 **노트북 액세스 토글**을 켜야 한다.

## 실습 사료

[`data/drag/`](data/drag/) — 두 PDF를 **긁어보기**와 **OCR 실습**에 모두 쓴다.
노트북 ①칸이 자동으로 내려받으므로 따로 준비할 것은 없다.

| 파일 | 자료 | 성격 |
|---|---|---|
| `drag_A_busan60.pdf` | 자료로 본 부산광복 60년 201~205쪽 | 글자층 **없음**. 344쪽 전체가 0자다 |
| `drag_B_gusulsa.pdf` | 구술로 보는 부산음악의 역사 발췌 | 글자층 있음. OCR이 필요 없다 |

**같은 뷰어에서 하나는 긁히고 하나는 안 긁힌다.** 그 차이가 이 시간의 출발점이다.

전 과정은 A의 **201쪽 「여성사회의 변화」** 한 쪽으로 돌린다.
순한글 · 가로쓰기 · 단 하나 · 사진 없음 — **가장 잘 되는 조건을 일부러 고른 것**이다.
여기서 안 되면 다른 자료에서는 더 안 된다.

## 자주 막히는 곳

**드라이브 keys 폴더에 파일이 없다.** 바탕화면에만 두면 코랩이 읽지 못한다.
발급 안내 5-2를 확인한다.

**보안 비밀 이름이 다르다.** 노트북 ②칸이 찾는 이름은 `GEMINI_API_KEY` 다.
대소문자와 밑줄까지 같아야 한다.

**노트북 액세스가 꺼져 있다.** 토글을 켜지 않으면 저장은 되어도 값을 읽지 못한다.

**칸을 건너뛰었다.** 앞 칸이 만든 것을 뒤 칸이 받아 쓴다. ④를 건너뛰고 ⑥을 누르면
「그런 이름 없다」는 오류가 난다. 고장이 아니라 순서 문제다.

## 비용

**Vision**은 월 1,000장까지 무료다. **Gemini**는 한 쪽에 몇 원 수준이며,
이날 실습 분량이면 십원 단위다. 자세한 것은 발급 안내 6절에 있다.

## 이 시간의 요지

줄어드는 것은 **옮겨 적는 시간**이지 **대조하는 시간**이 아니다.
기계는 빠르지만 틀리고, 틀린 자리를 스스로 알려주지 않는다.
오늘 만드는 것은 완성된 판독문이 아니라 **1차 가공물**이다.

원본과 나란히 놓고 보는 습관이 도구를 쓰는 능력보다 중요하다.
