# korean-ocr-lectures

AI 기반 고문서 OCR 강의·워크숍 자료 저장소다. 인문학 연구자를 대상으로 Google Cloud Vision API(텍스트 추출)와 Google Gemini API(문맥 교정)를 결합한 OCR 공정을 다루며, 강의별 실습 코드와 자료를 공개한다.

관련 저장소: [korean-modern-document-ocr](https://github.com/Song-yiJung/korean-modern-document-ocr) (연구·매뉴얼)

## 공통 자료

**[OCR 실습 사전 준비: Google Vision·Gemini API 키 발급 안내](./docs/api-key-setup.md)** — 모든 강의 공통. 실습 전에 완료해야 한다. 인쇄용 [PDF](./docs/OCR실습_API키_발급안내_20260813.pdf)도 함께 둔다.

> **2026년 8월 13일 개정** — Gemini 키를 결제 계정이 연결되지 않은 별도 프로젝트에서 발급하도록 바꾸었다. 요금 등급은 키가 아니라 프로젝트에 붙기 때문에, 결제를 연결한 프로젝트에서 만들면 무료 등급을 쓸 수 없다. 개정 이전 안내를 따라 키를 만든 경우 4장부터 다시 하면 된다.

## 이 저장소를 쓰는 법

각 강의 폴더의 `README.md`에 실습 순서와 준비물이 정리되어 있다. 노트북은 내려받지 않고 **맨 위의 `Open In Colab` 배지**를 눌러 브라우저에서 바로 연다. 원본은 읽기 전용이므로 `파일 → Drive에 사본 저장`으로 사본을 만든 뒤 작업한다.

## 다루지 않는 것

이 공정은 **텍스트 추출까지**를 다룬다. 검색 시스템을 만들어 주지도, 판독문을 완성해 주지도 않는다. 모델이 뽑아 준 텍스트는 1차 가공 데이터이며, 원본 이미지와 대조하는 연구자 검토를 거쳐야 학술적으로 쓸 수 있다.
