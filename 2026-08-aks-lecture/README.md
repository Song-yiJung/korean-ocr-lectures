## 사전 준비 — 강의 전까지 완료

[Google Vision·Gemini API 키 발급 안내](../docs/api-key-setup.md)

두 키는 발급처도 형태도 다르다. Vision 키는 콘솔에서 받는 **JSON 파일**이고, Gemini 키는 AI Studio에서 받는 **`AIzaSy…` 문자열**이다. 반드시 개인 구글 계정으로 발급한다. 기관 계정은 관리자 제한으로 키 생성이나 결제 설정이 막히는 경우가 있다.

## 실습 사료

「기부 물건에 관한 건」(昭和 10년) 한 문건의 세 면이다. 같은 문건 안에서 판독 난이도가 어떻게 달라지는지 본다.

| 파일 | 면의 성격 | 볼 것 |
|---|---|---|
| `E006-005-001-001` | 기안문 표지 — 붉은 서식 + 필사 | 형태 오독과 환각이 함께 나타난다 |
| `E006-005-001-002` | 이면 — 여백 위주, 흐린 필사 | 글자가 거의 잡히지 않는 면을 어떻게 다룰 것인가 |
| `E006-005-002-001` | 별지 통첩 — 인쇄 활자 | 조건이 좋을 때의 결과. 앞 두 장과 대조된다 |

조선총독부박물관 문서, 국립중앙박물관 소장. 교육 목적으로 사용한다.

## 오류가 났다면

- **`Colab Secret 접근 실패`** — 보안 비밀 이름이 노트북의 값과 글자 그대로 같은지, **노트북 액세스** 토글이 켜져 있는지 확인한다.
- **step2가 전부 오류로 멈춤** — 대개 step1의 Vision 키 이름을 그대로 둔 경우다. 폴더 두 값은 step1과 같게 두고, 키 이름만 Gemini용으로 바꾼다.
- **`교정 대상 0장` / `원본 이미지 없음`** — 두 노트북의 `INPUT_DIR`·`OUTPUT_DIR`이 서로 다르다. 글자 그대로 같아야 한다.

## 강의가 끝난 뒤

본인 사료에 적용할 때는 ③-보충 셀(샘플 내려받기)을 실행하지 말고, ③의 `INPUT_DIR`을 본인 이미지 폴더로 바꾼다. 사료의 시대·언어가 다르면 step2 ⑤번 셀의 교정 지침도 함께 고친다.
